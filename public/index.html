Claude Cockpit 在干什么

你要改本地项目里的顶栏登录按钮颜色。以前的做法是自己翻 src/App.jsx，把 btn-muted 改成金色。Vibecoding 换了一种干法：对着一条会话说人话，让带工具的模型去改那个文件。

驾驶舱不是又一个聊天网站。OpenCode / Claude Code / Cursor 才是干活的引擎；驾驶舱只是把本机已经存在的会话收进左侧列表，让你在浏览器里续上一轮、看图谱、开真终端。

先装 1 个 OpenCode 二进制、贴 1 把 API Key，端口 7799 就能聊。Claude 和 Cursor 是加餐，不是入场券。

三个词，从刚才那一轮推出来

  • 引擎：真正读文件、跑命令、改 src/App.jsx 的那个进程。驾驶舱里叫 OpenCode、Claude、Cursor、Hermes。驾驶舱自己不改你的代码。
  • 会话：同一条工作线程。有工作目录、有上一轮上下文。左侧列表里的一行，不是聊天 App 里的气泡墙。
  • 一轮：你发一条，引擎干活到交付。关掉 7799 的标签页只断了画面，轮次还在本机跑；OpenCode 的历史在 ~/.local/share/opencode。

Vibecoding 五条，写进这条会话就能用

  • 说要改哪，别说气氛。 有效的是 把顶栏登录按钮改成金色，文件是 src/App.jsx。无效的是 让页面高级一点。
  • 钉死工作目录。 新会话的工作目录就是引擎允许下爪的文件夹。怕乱改全盘，就把目录指到那个前端项目，而不是用户主目录。
  • 一小步验一次。 先改 className，刷新浏览器确认金色，再提清空按钮。两步两轮，比一句做完全站更不容易翻车。
  • Key 是账单，不是咒语。 DeepSeek 那把 Key 只写进本机 ~/.config/opencode/opencode.json。驾驶舱向导不会把 Key 送上公网口 7788。
  • 飞轮从 OpenCode 开始。 1 个二进制 + 1 把 Key 就能转。等左侧出现 OpenCode 分组，再决定要不要接 Claude / Cursor。
回到你现在这块屏 左侧是会话列表。第一次来先点 打开部署向导，把 OpenCode 和 Key 补齐，再点 ＋ OpenCode，把那句金色按钮的话发进去。已经会了就直接开聊；随时点左上角 ？ 回到这篇介绍。
